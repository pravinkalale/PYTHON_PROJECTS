Welcome to my Python Projects Repository! 

This repository contains my **console-based Python projects**, developed using Core Python. These projects help me improve my programming logic, problem-solving abilities, and practical understanding of Python.

## 🚀 My Projects

### 1. Student Management System 🎓
A console-based application designed to manage student records and perform student-related operations.

**File:** `Student_mgn_system/`

### 2. Notes App 📝
A simple console-based application that allows users to create, read, and manage notes using Python file handling.

**Files:** `note_app.py`, `notes.txt`

### 3. Fake Heading Generator 😂
A fun Python application that randomly combines subjects, actions, and places to generate unique, unexpected, and funny headings.

**File:** `fake_headline_generator.py`

**Sample Output:**
- A Monkey Dancing in the Classroom
- A Teacher Sleeping on the Moon
- A Programmer Cooking in the Jungle

Every execution generates a new random heading!

## 💻 How to Run These Projects

**1. Clone the repository**

```bash
git clone https://github.com/pravinkalale/PYTHON_PROJECTS.git
```

**2. Open the project folder in VS Code.**

**3. Run a project**

Student Management System:

```bash
python Student_mgn_system/main.py
```

Notes App:

```bash
python note_app.py
```

Fake Heading Generator:

```bash
python fake_headline_generator.py
```
